# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-05-20

### Added
- Interactive CLI with bilingual support (Chinese/English)
- Parallel SSH scanning and deployment
- Binary download with SHA256 checksum verification
- Local cache management with automatic cleanup
- JSONL-based update history tracking
- Symlink-based version management with auto-rollback
- SCP bandwidth limiting support
- Configuration via YAML with environment variable override
